== BasePlugin 全部方法(含私有) ==
- app(self)  // Flask app 引用（从 manager 获取），供插件注册中间件等使用。
- _get_i18n_dir(self) -> str  // Return absolute path to this plugin's i18n/ directory.
- _load_i18n(self)  // Pre-load this plugin's translation files.
- t(self, text: str, locale: str = None) -> str  // Plugin i18n: translate text using own i18n/{locale}.yml.
- setup(self)  // [ENABLED 阶段] 插件初始化。
- activate(self)  // [ACTIVE 阶段] 插件激活。
- deactivate(self)  // [DISABLED 阶段] 插件停用。
- on_install(self, registry) -> bool  // Called when plugin is first installed. Override to init DB tables etc.
- on_enable(self, registry) -> bool  // Called when plugin is enabled. Override to set up resources.
- on_disable(self, registry) -> bool  // Called when plugin is disabled. Override to clean up resources.
- on_uninstall(self, registry) -> bool  // Called when plugin is uninstalled. Drop tables, clean config.
- register_routes(self) -> List  // Return a list of Flask Blueprints to register.
- register_jobs(self) -> List[Dict[str, Any]]  // Return a list of APScheduler job config dicts.
- register_dag_nodes(self) -> Dict[str, Any]  // Return {node_type: handler_function} for DAG workflow engine.
- register_health_checks(self) -> List[Dict[str, Any]]  // Return a list of health check item dicts.
- get_event_handlers(self) -> Dict[str, Callable]  // Return {event_name: handler_function} to subscribe to system events.
- get_config_value(self, key: str, default: Any = None) -> Any  // Get a plugin config value from plugin.json 'config' section.
- set_config_value(self, key: str, value: Any) -> bool  // Set a plugin config value and persist to database.
- log(self, message: str, level: str = 'info')  // Log a message with plugin name prefix.
- validate_config(self) -> List[str]  // Validate _config against config_schema. Return list of errors.

== manager_api methods ==
- init_app(self, app)  // 工厂模式初始化，绑定到 Flask 应用
- discover(self) -> List[PluginInfo]  // 扫描 plugins/ 目录，返回新发现的插件列表
- discover_all(self) -> List[PluginInfo]  // 扫描并返回所有插件（含已注册的）
- install(self, identifier: str) -> PluginInfo  // 安装插件: 写入 registry 持久化, 状态 → INSTALLED
- enable(self, identifier: str) -> PluginInfo  // 启用插件: 检查依赖 + 执行 setup(), 状态 → ENABLED
- activate(self, identifier: str) -> PluginInfo  // 激活插件: 加载模块 + 注册路由/钩子, 状态 → ACTIVE
- disable(self, identifier: str) -> PluginInfo  // 禁用插件: 反注册路由/钩子, 状态 → DISABLED
- uninstall(self, identifier: str) -> None  // 卸载插件: 禁用 + 清理 + 移除 registry 记录
- upgrade(self, identifier: str) -> dict  // 从商店升级插件到最新版本（在线更新）。
- get_all_stats(self) -> dict  // 聚合所有 ACTIVE 插件的 get_dashboard_stats()。
- register_all_dag_nodes(self, engine) -> int  // 将 ACTIVE 插件的 register_dag_nodes() 注册到 WorkflowEngine。
- register_all_plugin_jobs(self, scheduler) -> int  // 将 ACTIVE 插件的 register_jobs() 注册到 SchedulerEngine（APScheduler 进程内）。
- install_all(self) -> List[str]  // 安装所有已发现但未注册的插件
- enable_all(self) -> List[str]  // 启用所有已安装的插件
- activate_all(self) -> List[str]  // 激活所有已启用的插件
- mount_active_routes(self)  // 启动期挂载所有 enabled/active 插件的路由（必须在首个请求前调用）。
- mount_all_routes(self)  // 启动期挂载**所有已安装插件**（含 disabled）的路由 + 注册前缀映射。
- is_path_allowed(self, path: str) -> bool  // 门卫：判断请求路径对应的插件是否处于启用状态。
- refresh_status_from_db(self)  // 重新从 plugin_registry 读取各插件状态，刷新内存缓存中的 status。
- get_info(self, identifier: str) -> Optional[PluginInfo]  // 获取插件信息（从缓存）
